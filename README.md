# JARVIS

## Website

Visit the JARVIS interface at **https://python-masterr.github.io/JARVIS/**. It connects directly to the JARVIS API running on your own computer; your conversations and API key are not hosted by GitHub Pages.

To use it, install and start the local API by following the [JARVIS setup guide](jarvis-phase1/jarvis/README.md), then run `python -m jarvis_core show-token` and paste the token into the website.
